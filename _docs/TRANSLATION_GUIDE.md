# ほらあな哲学書庫 翻訳・追加ガイド

このファイルは、書庫に作品を追加するときの手順書です。サイトに関する判断の根拠は `_docs/STRATEGY.md` に記録する。手順書にない判断をしたときは、その根拠を `_docs/STRATEGY.md` の意思決定の記録に1行追加する。サイト全体が書庫で、トップページは `index.html`、作品ページは `philosophy/`、ビューワーは `philosophy/reader.css` と `reader.js`。`book.html` は旧URLからトップへ転送するだけのページなので編集しない。`_archive/` は以前の個人サイトの非公開保管庫なので触らない。定期実行のエージェントも、人が手で追加するときも、この手順に従ってください。

## 方針

- **全文を訳し終えた作品だけを公開する。** 途中の訳は `_drafts/` に置いて非公開にする。
  (GitHub Pages は `_` で始まるフォルダ・ファイルを公開しないので、`_drafts/` と `_template.html` はサイトに出ない。)
- 対象は、原典がパブリックドメインで、**青空文庫に収録されていない**西洋の哲学・思想の古典(政治思想・社会学・神学・精神分析を含む)。
  青空文庫の作品目録 CSV(`https://www.aozora.gr.jp/index_pages/list_person_all_extended_utf8.zip`)で確認する。
- 必ず**原典の原文をネットから取得して照合しながら**訳す(Project Gutenberg、The Latin Library、Perseus など)。
  原文が取得できなかった部分がある場合は、ページの「原典・参考」にその旨を正直に書く。
- **著作権を守るためのルール:**
  - 原典は、日本で保護期間が切れたもの(著者が1967年以前に亡くなっていて、戦時加算を考えても切れているもの)だけを扱う。
  - 照合に使う英訳などは、パブリックドメインの古い訳(Project Gutenberg 収録のものなど)だけにする。近年の訳は使わない。
  - **著作権のある既存の日本語訳(岩波文庫・光文社古典新訳文庫などの訳文)は、取得も参照もしない。** 訳文は原文から独自に作る。
  - 原文の校訂版の注や解説は写さない。訳注は自分で書く。
- 大著も対象。何十回かかっても下書きで訳し進め、全文が終わった時点で公開する。
- 原文がネットで見つからない作品も飛ばさない。パブリックドメインの英訳などと照合して訳し、そのことをページの「原典・参考」に明記する。

## 訳文のスタイル

- 地の文は「である」調。対話・弁論・書簡で語りかける文体の原典は「です・ます」も可。
- 専門用語は定訳に合わせ、初出で訳注をつける(例:悟性、表象、実体)。
- 原文にない説明を本文に足さない。補足は訳注へ。**本文を省略しない**(全訳なので「……」による省略は使わない)。
- 冒頭に `<div class="note">` で作品と著者の紹介(3〜5文)。末尾に訳注と「原典・参考」。
- 同じ作品の中で、訳語・文体・節番号の付け方を揃える。続きを訳すときは、まず既存の訳を読んで合わせる。

## 進め方(1回の実行でやること)

1. 下の「全訳計画」の上から、**まだ公開されていない最初の作品**を選ぶ。
2. その作品の下書き `_drafts/<スラッグ>.html` があれば続きから、無ければ `philosophy/_template.html` をコピーして下書きを作る。
3. 1回の実行で、無理なく質を保てる量(目安:原文で1〜2章、または1部・1巻)を訳して下書きに追記する。
   既存の下書きに「抜粋」のための飛ばしがある場合は、飛ばした部分も埋める。
4. 下書きのページの先頭近くに `<!-- 進捗: ○○まで訳了 / 全体は△△ -->` のコメントを置き、毎回更新する。
5. 毎回、下書きの進捗コメントに「今回訳した原文の語数(概数)」も書き足す。翻訳スピードの見積もりを実測で直すために使う。
6. **全文が訳し終わったら公開する:**
   - `git mv _drafts/<スラッグ>.html philosophy/<スラッグ>.html`
   - `{{RANGE}}` 相当の表示(表紙・タイトル・説明文・JSON-LD の name)を「全訳」にする。進捗コメントを消す。
   - トップページ `index.html` の「書棚」(`<ul class="shelf">`)に、既存と同じ形の `<li>`(`<a class="book-cover" ... style="--cover:色">` の表紙と `book-info`)を年代順の位置に追加する。表紙の色は既存と被らない落ち着いた濃い色にする。
   - 同じページ先頭の JSON-LD の ItemList に追加し、「翻訳中」(`<ul class="wip">`)からその作品を消す。
   - 「翻訳中・次に公開予定」の一覧には、いま進めている期の未公開作品を計画の順に並べる。その期が終わったら次の期の作品に入れ替える。
   - `sitemap.xml` に URL を追加し、`lastmod` を今日の日付にする。
   - 下の全訳計画のその行に「公開済み」と書く。
   - 公開する回の PR 本文には、下の「人による校閲」のチェックリストを入れる。

## 人による校閲(公開前に必ず)

全訳が終わった作品は、**持ち主が通読して手を入れてから公開する。** 人の手が入ることで訳文に権利が生まれ、品質も上がる。利用条件ページ(`terms.html`)も、この工程を前提に書いている。

- 公開する PR は、持ち主が次のチェックを終えるまでマージしない。PR 本文にこのチェックリストを入れる。
  - [ ] 全文を通読した
  - [ ] 訳語・言い回しを自分の言葉で選び直した箇所がある(気になったところを直す)
  - [ ] 誤字・読みにくい文を直した
- 持ち主が PR にコメントで直しを頼んだ場合は、定期実行が次の回でそれを反映する。
- 持ち主が自分で直したコミットは、そのまま残す(上書きしない)。

## ページの作り方(テンプレートの埋め方)

- `{{WORK}}` 作品名、`{{AUTHOR}}` 著者名、`{{DATES}}` 生没年、`{{RANGE}}` は公開時「全訳」、`{{LANG}}` 原典の言語。
- `{{URL}}` は `https://dr-sakamoto.github.io/hitomi-site/philosophy/<スラッグ>.html`
- `{{DESC}}` は検索結果に出る説明文(80〜120字)。作品名・著者名・「日本語訳」「全文」「無料」・有名な一節を入れる。
- `{{JSONLD}}` は公開済みページ(例:`philosophy/kant-aufklaerung.html`)の JSON-LD と同じ形の Book オブジェクト。
- `{{BODY}}` の構成:紹介の `note` → 本文(`<h2>`、`<p>`、節番号は `<span class="num">`)→ 訳注の `note` → `<div class="note colophon">` の原典・参考。

## 確認

- Playwright で対象ページを開き、JS エラーがないこと、縦書き・横書きの両方でページ数が表示されることを確かめる。
- 公開した回は、`index.html` から新しいページへのリンクが切れていないことも確かめる。

## 全訳計画(この順に、すべて訳し切る)

日本での知名度と長さ(必要な実行回数)の両方を考え、少ない回数で有名な作品を公開できる順に並べている。
短い作品を先に公開して書庫を育てつつ、長い名著も最後まで訳し切る。打ち切りはしない。
「回数」は1回あたり原文約4,000語と**仮定した**目安で、実測の根拠はない。作品の長さの実測値と、1回あたりの翻訳量の記録は `_docs/STRATEGY.md` にある。実測がたまったら回数を直す。
