# ほらあな哲学書庫 戦略と意思決定の記録

サイトに関する判断は、必ずこのファイルに**根拠・証拠・確からしさ・検証方法**を残す。
根拠が弱い判断は「仮説」と明記し、検証できるデータが手に入ったら見直す。

## 1. 目的と指標

- **目的**:日本語で無料の全訳が存在しない西洋の哲学・思想の古典を全訳して公開し、検索流入を集めて収益化する(広告・書籍アフィリエイト)。
- **想定読者**:哲学・思想の古典を「無料で」「日本語で」読みたい人。授業やレポートで原典を確認したい学生、教養として読みたい社会人。
- **指標(Search Console と、導入後はアクセス解析で測る)**
  1. インデックスされたページ数
  2. 検索での表示回数・クリック数・掲載順位(作品名+「全文」「無料」「日本語訳」などのクエリ)
  3. ページビューと読了率(最後のページまでめくった割合)
  4. 収益(広告・アフィリエイト)

## 2. 競争上の前提

| 前提 | 根拠・証拠 | 確からしさ |
|---|---|---|
| 「青空文庫にない古典の全訳」は日本語の検索で競合が少ない | 青空文庫の作品目録 CSV で計画の44作品が未収録であることを確認済み。既存の日本語訳は有料の文庫本が中心 | 中(検索結果の競合サイトはまだ調べていない) |
| 英語などへの多言語展開は勝ち目が薄い | 英語には Project Gutenberg などに無料の定番訳が多数ある | 中 |
| 抜粋より全文のほうが評価されやすい | Google は内容の薄いページの量産を低く評価する方針を公表している。読者にとっても全文のほうが価値が高い | 中 |
| 訳文だけでは模倣を防げない | AI だけで生成した文章には著作権が生じにくいとされる(文化庁の考え方) | 中 |

| 2026-11-08 | サイト全体を書庫専用にする | テーマが一つに絞られたサイトのほうが検索で評価されやすいという一般的な SEO の考え方 | 中 | 書庫ページの順位の推移 |
| 2026-11-08 | 公開順は「知名度 ÷ 長さ」 | 早く、検索需要のある作品のページを増やすため | **低**。知名度は私の感覚による判断で、検索ボリュームのデータは使っていない | キーワードプランナーなどで検索ボリュームを調べて並べ直す |
| 2026-11-08 | 実行は週2回 | **戦略的な根拠なし**。「着々と」という依頼から感覚で決めた | 低 | コスト(利用量)と完了時期のバランスで決め直す |
| 2026-11-08 | 1回あたりの翻訳量は原文約4,000語と仮定 | **実測なし**。「1回1〜2章」という感覚的な仮定 | 低 | 定期実行の各回の語数を記録して実測で直す(翻訳ガイドに記録手順あり) |
| 2026-11-08 | 公開前に人が通読して手を入れる | 人が創作的に関与した部分に権利が生じる → 模倣への法的な対抗手段になる。品質も上がる | 中 | 誤訳の指摘件数 |
| 2026-11-08 | 戦略メモと手順書を `_docs/` に置き、サイトに出さない | 競合に方針・手順・計画を読まれないため。ただしリポジトリが公開設定なので GitHub 上では読める | 中 | リポジトリの非公開化を持ち主が判断する(GitHub Pages を非公開リポジトリから出すには有料プランが必要) |
| 2026-11-08 | 読書設定(書字方向・文字サイズ・1ページの行数・1行の文字数・行間・書体・背景)を選べるようにする | 読みやすさは端末・視力・好みで大きく変わる。合わせられれば読了率と滞在時間が上がり、検索評価と広告収益に効く。本文の HTML は変えないので SEO への悪影響はない。ゴシック体は選んだ人にだけ読み込み、表示速度を落とさない | 仮説 | 読了率・滞在時間(計測にはアクセス解析の導入が必要) |
| 2026-11-08 | 利用条件ページを置く | 転載・商用利用への抑止、問い合わせ窓口 | 中 | 無断転載の発見件数 |

## 5. 次に集めるべき証拠

1. Search Console の登録とサイトマップ送信(持ち主の作業)→ インデックス状況と検索クエリ
2. 作品名ごとの検索ボリューム(キーワードプランナー、Google トレンド)→ 公開順の見直し
3. 定期実行の1回あたりの翻訳語数 → 完了時期と実行頻度の見直し
4. 主要クエリでの検索結果の競合サイト調査 → 2章の前提の確認
5. アクセス解析(読了率・滞在時間・どの読書設定が使われているか)→ ビューワーの改善
